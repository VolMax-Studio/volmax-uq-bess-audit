# Battery SOH Uncertainty Quantification (UQ) Audit

This repository contains the code, data loader, and results for an independent Uncertainty Quantification (UQ) audit of a State of Health (SOH) machine learning predictor. 

The audit evaluates the risk of using deterministic **point estimates** for battery cycle life prediction under Out-of-Distribution (OOD) dynamic charging conditions and implements Conformal Prediction wrappers to evaluate prediction intervals.

## Key Findings & Verdict
* **The Overconfidence Trap:** The baseline SOH point predictor degrades significantly under OOD testing (RMSE increases by **35%** from 172 to 233 cycles). However, the deterministic point estimator provides no signal of this degradation, exposing operators to uncalibrated predictions.
* **Locally Adaptive Conformal Calibration:** Wrapping the model with **Additive Locally Adaptive Conformal Prediction** bounds the uncertainty, but the intervals become bloated under OOD shift (mean width of **1525.48 cycles** compared to 1172.77 cycles in-distribution). This reflects the loss of exchangeability guarantees under distribution shift.
* **Hybrid OOD Detection:** Combining **Mahalanobis Distance** and **Isolation Forest** reveals that OOD profiles manifest as extreme local outliers (Mahalanobis distances peaking at **32.46** with regularized Ledoit-Wolf covariance compared to ID average of ~3.9). Since 95% of OOD cells hide within the ID bulk, feature anomaly detection alone is insufficient, making predictive UQ essential.
* **Verdict:** **INSUFFICIENT UNDER OOD SHIFT.** While UQ is necessary to expose model limits and avoid overconfident point failures, it is insufficient on its own to enable robust operation under distribution shift, as conformal intervals balloon to an average of **1525.48 cycles** (rendering the uncertainty bounds practically useless for operational dispatch scheduling).
* **Business Impact:** Overconfident predictions directly harm battery warranties, electricity market bidding profits, and project economics.

For a detailed analysis, see the [Independent UQ Verification Report (uq_audit_report.md)](uq_audit_report.md).

## Repository Structure
* `model_audit.py` — Replicates the baseline multi-feature SOH model.
* `conformal_wrapper.py` — Implements standard and additive locally-adaptive Conformal Prediction wrappers.
* `bess_stress_test.py` — Executes the stress-testing suite on OOD charging protocols.
* `reproduce.py` — High-level script that runs the pipeline, checks validation, and saves figures.
* `uq_audit_report.md` — The formal audit report documenting the findings.
* `results/` — Folder containing JSON metrics and plots.

## How to Run & Reproduce

### Prerequisites
Make sure you have Python 3 installed with the required libraries:
```bash
pip install numpy pandas scikit-learn matplotlib
```

### Running Validation Tests
To run the automated validation suite (which checks if the calibration set guarantees nominal 90% coverage):
```bash
python3 reproduce.py --test-only
```

### Reproducing All Results & Plots
To run the entire stress-testing suite and regenerate the diagnostic figures:
```bash
python3 reproduce.py
```
This will save:
* `results/audit_results.json` — Evaluated metrics.
* `results/conformal_intervals.png` — Interval coverage plot on the OOD set.
* `results/reliability_curve.png` — Calibration curve (nominal vs. observed coverage).
